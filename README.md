# Exercício acadêmico 01 · Apresentação pessoal

Primeiro exercício de apresentação pessoal em HTML e CSS, preservado como registro de aprendizado.

## Conteúdo

- `index.html`: página estática com texto de apresentação, estilos incorporados e imagens externas.
- Sem dependências de instalação ou etapa de build.

## Como visualizar

Baixe o repositório e abra `index.html` em um navegador. As imagens dependem dos serviços externos referenciados no código e podem deixar de carregar.

## Contexto histórico

O texto da página registra o momento em que o exercício foi criado; idade, curso e planos mencionados ali não são uma biografia atual. O código original foi mantido.
